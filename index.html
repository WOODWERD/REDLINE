Guide

Start a review

Drop a PDF anywhere on this page, or press Open a PDF. You can also attach a PDF in a chat with Claude and say “redline this”. Claude adds it to the library and sends you the link.

The same file always opens the same document, so markups come back when you drop it again.

Your PDF stays on your computer. Nothing is uploaded, and your markups are saved in this browser until you clear its data.

Mark up

VSelect, move, Delete removes HPan (or hold Space) CCloud an area RBox AArrow TCallout with note text PPen IHighlight MMeasure at the chosen scale WFit width · Ctrl 0 fit page

Measurements use the PDF's own sheet size, so a 36 × 24 sheet measures true at its printed scale. A set printed to a smaller sheet will not.

Send it back

Type your name and press Download marked-up PDF. Send the file back however you like: email, text, a shared folder. Each markup is a real PDF comment, so it shows in Bluebeam, Acrobat, Preview or any PDF viewer.

Send for review

Markups stay drafts until you press Submit. Claude gets the batch, works each one, and replies under it here.

Answer Claude

Under each reply, press Approve plan (or Accept and close when it's done), or Answer / change to send a rework note. Your responses go out with the next Submit. Accepted, finished markups close and drop out of the open count. Needs my review in the filter shows what's waiting on you.

Send a PDF to someone

How it works

Three steps, no account needed.
  1. Open the PDF. Pick Cloud, Arrow or Callout and drag on the drawing.
  2. Type what should change in the comment box beside each markup.
  3. Type your name, press Download marked-up PDF, and send the file back however you like.
02

Start from a chat

The quickest way to kick off a review on a new set.
  1. Attach the PDF in any chat with Claude and say “redline this”.
  2. Claude adds it here and replies with a link straight to page one.
  3. Mark it up, then press Submit. Claude works each markup and answers under it.
